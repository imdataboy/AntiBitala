# AntiBitala

AntiBitala is a local-first Morocco company database for job seekers.

The goal is to help users find reliable companies, official websites, career pages, contact pages, public company emails, and source-backed information.

## Run locally

```bash
git clone https://github.com/YOUR_USERNAME/AntiBitala.git
cd AntiBitala
uv sync --frozen
uv run antibitala
